# ♟️ Python Chess Game

A fully functional Chess game built using Python.  
The project focuses on core game logic, object-oriented programming, and clean code structure, making it ideal for learning and demonstrating Python skills.

---

## 📌 Features

- Standard chess rules implementation
- Two-player mode (local)
- Turn-based gameplay
- Legal move validation
- Check and Checkmate detection
- Console-based or GUI-based (depending on implementation)
- Clean and readable Python code

---

## 🛠️ Technologies Used

- Python 3.x  
- (Optional) Pygame / Tkinter for GUI  
- Object-Oriented Programming (OOP)
